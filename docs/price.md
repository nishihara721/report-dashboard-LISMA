# Firebase 料金について

---

## プラン構成

Firebaseには2つのプランがあります。

| プラン | 料金 | 特徴 |
|---|---|---|
| **Spark（無料）** | $0 | 無料枠内のみ使用可 |
| **Blaze（従量課金）** | 使った分だけ | 無料枠を超えた分のみ課金 |

**Firebase App Hostingの使用にはBlazeプランへのアップグレードが必須です。**
クレジットカードの登録が必要ですが、無料枠内であれば費用は発生しません。

## 今回のツールでの費用試算

### Firestore（DB）の読み書き回数

**1日あたりの書き込み回数（1案件）：**

GASは1日1回手動実行されます。

| コレクション | 1日の書き込み行数 |
|---|---|
| daily_reports | 1行 |
| daily_reports_by_p | 約2行 |
| daily_reports_by_s | 約2行 |
| daily_reports_by_exit | 約4行 |
| daily_reports_by_appeal | 約2行 |
| 合計 | 約11行/日 |

1案件あたり約11回/日 << 無料枠20,000回/日

**20案件の場合：** 約220回/日 << 無料枠20,000回/日

### Firebase App Hosting

社内ツールのアクセス頻度（業務時間内のみ・少人数）であれば、Cloud Runの無料枠（200万リクエスト/月）に収まる可能性が高いです。

## 注意点

### ① 上限なしの従量課金

Blazeプランは使った分だけ課金されます。予期せぬ大量アクセスや無限ループが発生した場合、予想外の費用が発生する可能性があります。

**対策：** Google Cloudコンソールで予算アラートを設定してください。

```
Google Cloudコンソール → 請求 → 予算とアラート → 予算を作成
```

### ② Firebase App Hostingは案件ごとにプロジェクトが必要

1つのFirebaseプロジェクトに複数の案件のデータを混在させることもできますが、セキュリティ・管理のしやすさの観点から案件ごとにプロジェクトを分けることを推奨します。

各プロジェクトに無料枠が適用されるため、案件数が増えても費用は増えません。

### ③ Cloud Buildのビルド時間

GitHubにpushするたびにCloud Buildが実行されます。1回のビルドに約5〜10分かかるため、頻繁にpushする場合は無料枠（2,500分/月）を消費します。

月500回程度のビルドまでは無料枠内に収まります。
